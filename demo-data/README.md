# Demo Data

This folder will hold fictional, static demo context data for the generative Apple Watch UI simulator.

The data is intended to make component content and AI-generated UI examples feel realistic without using live integrations or real personal data. Design rules belong in `design-pack/`; demo content belongs here.

Use `pseudo-context.md` for human-readable brainstorming. Convert the approved content into `pseudo-context.json` later when the data shape is ready.
